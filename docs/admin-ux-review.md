# 管理后台体验优化

本次改动位于 `albireo-admin`，保留 `src/assets/albireo-logo.png` 原狐狸图标，统一工作台、内容管理与系统管理页面的布局和反馈。

主题以浅绿、薄荷绿和鼠尾草绿为主，深绿色用于文字和主操作以保持可读性；导航、工作台功能图标、登录页、地图标记及表单选中状态使用同一配色。狐狸品牌图标使用黑底黄色，侧栏、工作台、登录页和网站图标共享同一个 SVG；SVG 内嵌原始狐狸图片并着色，保留原有轮廓和原始图片文件。

## 页面与交互

| 范围 | 改动 |
| --- | --- |
| 全局导航 | 分组侧栏、收起状态记忆、面包屑、页面搜索（Ctrl / Cmd + K）、移动端抽屉与键盘焦点管理 |
| 工作台 | 接入实际 API 的内容计数与任务概览、常用入口、局部加载失败提示 |
| 图片与视频 | 搜索筛选、选择反馈、批量操作成功/失败计数、删除确认、字段保存队列、响应式编辑抽屉 |
| 上传 | 修复全局拖入事件、避免重复选择和重复提交、明确队列状态与清理逻辑 |
| 合集 | 修复 API 分页总数解析、编辑/封面保存反馈、封面选择加载与空状态、触屏可见操作 |
| 标签与评论 | 查询状态、输入校验、删除处理中反馈、回复展开与移动端布局 |
| 分享 | 筛选覆盖服务端各页，修复仅搜索当前页的问题；操作防重、过期时间和次数校验 |
| 任务与系统 | 加载失败重试、刷新/重试防重、离开页面清理轮询、可折叠任务面板、配置与模型保存反馈 |
| 地图 | 移除示例坐标，连接现有聚合 API，提供聚合标记、素材入口、底图切换与加载/失败状态 |
| 登录与账户 | 小屏表单、提交防重、登录后返回原页面、密码字段自动填充语义 |

动画包括页面进入、侧栏展开、卡片和按钮反馈以及工作台狐狸装饰的轻微浮动。系统启用“减少动态效果”时统一缩短动画。

## 正确性修复

- 视频批量修改可见性只提交 `visibility`，保留原有标题和描述。
- 合集兼容当前后端包装数组及每行 `COUNT(*) OVER()` 的总数格式，错误响应不会被当作空列表。
- 搜索和筛选使用请求序号，避免旧请求覆盖新结果。
- 编辑抽屉固定异步保存的素材 ID；标签、位置和 EXIF 丢弃切换前的旧响应；按字段排队保存并保留失败草稿。同一素材更新时不重置仍在编辑的内容。
- 同坐标的地图素材合并为一个标记，在可滚动弹窗中提供每个素材的独立入口。
- 视频截帧提供实际截图下载；界面明确说明视频封面仍由现有处理流程生成。
- 路由按页面懒加载，补齐实际使用的 `vue-router` 依赖。

## 验证

- `npm test`：4 项合集响应归一化测试，覆盖包装数组、空数据、标准分页格式和异常响应。
- `npm run build`：TypeScript 检查与 Vite 生产构建。
- 浏览器检查：桌面与 390px 移动视口；工作台、图片、视频、合集、标签、评论、分享、上传、任务、系统配置、视觉模型、向量嵌入、重新处理、账户和地图。
- 隔离模拟接口验证：第 201 条分享可以跨页搜索到；批量视频更新的部分失败计数准确且仅提交可见性字段；Delete 快捷键先确认；网络错误显示重试而非空数据提示。
- 最终交互验证：标签创建等待时切换视频仍写入原视频；第二张图片的位置不被第一张的延迟响应覆盖；标题保存不清空后续描述输入；同坐标图片和视频均有入口；390px 抽屉与经纬度输入无横向溢出。
- 临时模拟入口已删除。浏览器预览使用模拟数据，没有修改真实业务数据。

当前浏览器未登录，因此真实账户下的上传、保存、删除、重试任务等后端写入链路尚未联调。Vite 仍提示 Naive UI / MapLibre 等依赖分块较大，生产构建可以正常完成。
